# Live dotfiles

Some configs are linked **out of the Nix store** straight to the repo, so
editing them takes effect without a rebuild:

| Config | Lives in repo | Linked to | Reload |
|--------|---------------|-----------|--------|
| Hyprland | `home/configs/hypr/` | `~/.config/hypr` | automatic / `hyprctl reload` |
| Neovim | `home/configs/nvim/` | loaded by the Neovim wrapper | restart nvim |
| zsh extras | `home/configs/zsh.d/` | `~/.config/zsh.d` | new terminal |
| Caddy | `home/configs/caddy/Caddyfile` | `~/.config/caddy/Caddyfile` | `caddy-reload` |

This depends on one setting:

```nix
mercury.home.environment.configsPath = "/home/mercury/MercLab/home/configs";  # the default
```

If the repo is somewhere else on a machine, set it in that host's profile list.
If the repo is missing, these links dangle and the apps start with no config —
clone the repo back to `~/MercLab`.

Set `configsPath = null;` to use read-only copies baked into the build instead
(each change then needs `mcli switch`). Individual apps also have their own
`configsPath` option to opt out one at a time.

Everything else (Wayle, kitty, git, GTK…) is generated by Nix: edit the `.nix`
file and `mcli switch`.

> Edits to live files are still just files in the repo — commit them.
